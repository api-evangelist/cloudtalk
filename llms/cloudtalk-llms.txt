# CloudTalk

> CloudTalk is an AI-powered cloud call center and business phone system (CCaaS) for sales and
> support teams. Its REST API (https://my.cloudtalk.io/api, OpenAPI v1.7) manages calls, contacts,
> agents, groups, phone numbers, campaigns, tags, SMS, and blacklists, and exposes Conversation
> Intelligence (transcription, sentiment, topics, smart notes) and VoiceAgent calling. Authentication
> is HTTPS-only HTTP Basic Auth (API Access Key ID + Secret). JSON only; 60 requests/min per company.

## APIs

- [CloudTalk API Reference](https://developers.cloudtalk.io/): REST API for the CloudTalk call-center platform.
- [OpenAPI (swagger.json)](https://developers.cloudtalk.io/swagger.json): Published OpenAPI 3.0.1 document, version 1.7.
